📖 阶段一：认知建立 第 1-2 天，约 2 小时

搞清楚"Vibe Coding 到底是什么"、"我能用它做什么"
  • 读：Vibe Coding 百度百科 + 写给设计师的零基础指南前言
  • 读：7 天从想法到上线 Day1 — 了解完整学习路径
  • 动手：用自然语言让 AI 生成一个个人介绍页面，保存为 HTML 双击打开
  • 能用自己的话解释 Vibe Coding 是什么
  • 能说出前端、后端、数据库分别管什么
  • 成功在浏览器里看到一个 AI 生成的页面

🛠️ 阶段二：工具与流程 第 3-4 天，约 3 小时

选一个工具安装好，学会写 PRD，跑通第一个完整流程
  • 选工具安装（推荐 TRAE 国内版，免费+中文好）
  • 用 PRD 模板写一份项目说明书
  • 把 PRD 交给 AI，做至少 3 轮迭代修改

🚀 阶段三：第一个项目 第 5-7 天，约 5 小时

从零到一完成一个完整项目并部署上线
  • 跟做 Vibe Vibe 开源教程 · 实践篇
  • 完成个人作品集网站 → GitHub 上传 → Cloudflare/Vercel 部署 → 获得网址
  • 把网址发给朋友，收集反馈

🔮 阶段四：进阶扩展 第 2-4 周，持续

加入后端逻辑，让产品有"记忆"和"交互"
  • 给项目加后端功能（联系表单、留言板、AI 对话）
  • 学习使用环境变量保护 API Key
  • 尝试不同工具（TRAE → Cursor），做第 2 个项目
